# Content Farm Italia

Inchiesta interattiva di Liberi Network sulle pagine Facebook gestite dall'estero che pubblicano contenuti su Giorgia Meloni per il pubblico italiano.

- `index.html`: la pagina
- `js/`: il codice delle quattro sezioni (contesto, mappamondo, contenuti, reti)
- `data/`: pagine, post, legami tra pagine, miniature delle immagini, geometrie del mondo
- `media/`: immagini in alta qualità e logo

Dati: rilevazione 13–14 ottobre 2026.
